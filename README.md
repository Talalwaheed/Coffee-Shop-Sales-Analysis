# Coffee Shop Sales Analysis :

A complete data analysis project built to evaluate sales performance, profitability, 
and growth trends for a coffee shop business. The project covers everything from raw 
data cleaning to machine learning-based profit forecasting.

## Overview :

This project analyzes over 15,000 real sales transactions from a coffee shop to answer 
one core question — which products are actually driving profit, and which ones are 
dragging it down. The findings are backed by visualizations, trend analysis, and a 
predictive model that forecasts profit with near-perfect accuracy.

## What Was Done :

- Imported and cleaned raw sales transaction data
- Calculated revenue, cost, and profit for each product category
- Ranked products by total profit to identify top and low performers
- Analyzed monthly profit trends from March to November 2023
- Built a Random Forest model to predict profit based on price and quantity
- Auto-generated a PowerPoint summary and business recommendations

## Key Results :

- Coffee ranked as the highest profit-generating product category
- The business showed consistent month-over-month profit growth throughout 2023
- The machine learning model achieved an R-squared score of 0.9999 and a Mean 
  Absolute Error of just 0.00001, confirming strong predictive reliability
- Branded products and Tea followed closely behind Coffee in profitability

## Tech  :

- Python (Pandas, NumPy, Matplotlib, Plotly)
- Scikit-learn (Random Forest Regressor)
- Google Colab
- python-pptx for automated report generation
